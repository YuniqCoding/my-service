# PRD 세 줄 요약

## 언제 쓰나

- PRD.md 를 요약해 달라고 할 때
- 내 서비스가 무엇인지 짧게 알려 달라고 할 때

## 무엇을 받나

- 지금 연 폴더 맨 위의 `PRD.md`

## 어떤 순서로 하나

1. `PRD.md` 를 읽는다
2. 누구를 위한 서비스인지, 넣을 기능이 무엇인지, 비목표가 무엇인지 찾는다
3. 한 줄에 하나씩 적는다

## 무엇을 내놓나

번호를 붙인 세 줄로 답한다.

1. 누구를 위해 무엇을 하는 서비스인가
2. 넣을 기능
3. 만들지 않는 것 (비목표)

- 세 줄 요약을 지금 연 폴더 맨 위의 summary.md 파일로 저장한다. 파일이 이미 있으면 새 내용으로 덮어쓴다

## 지킬 것

- `PRD.md` 에 없는 내용은 지어내지 않는다
- `PRD.md` 는 읽기만 하고 고치지 않는다
- `PRD.md` 에 근거가 없는 자리는 채우지 말고 `(질문 필요)` 로 둔다
