# 화면 만들 때 규칙

- 화면의 버튼 이름, 칸 이름, 안내 문구는 PRD.md 에 적힌 글자를 그대로 쓴다 (예: [만들기], "사진을 1장 올려 주세요")
- 화면은 화면 1 · 넣는 화면, 화면 2 · 나오는 화면, 화면 3 · 올리고 모아 보는 화면 세 장만 만들고, 다른 화면은 더하지 않는다
- 예외 : 관리 화면 한 장은 둔다. 관리자(st.secrets 의 ADMIN_EMAILS 에 메일이 있는 사람)에게만 사이드바 「관리」 버튼이 보이고, 관리자가 아니면 관리 화면 코드도 돌지 않게 한다
