# 저장·데이터 다룰 때 규칙

- 결과물은 사진 1장과 이름이 있어야 올라가고, 한 줄 설명은 비어 있어도 올라가게 만든다
- 이름은 submissions 표의 owner 칸에 같이 적고, 갤러리에는 owner 가 지금 넣은 이름과 같은 결과물만 보여 준다. 이름이 비어 있으면 "이름을 넣어 주세요" 를 띄운다
- 여러 사람이 동시에 올리는 기능은 PRD.md 비목표이므로 만들지 않는다
- 로그인은 Streamlit 의 st.login 으로 구글 계정만 쓴다. 키 값은 .streamlit/secrets.toml 에만 두고 코드에 적지 않는다
