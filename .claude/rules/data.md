# 저장·데이터 다룰 때 규칙

- 결과물은 사진 1장이 있어야 올라가고, 한 줄 설명은 비어 있어도 올라가게 만든다. 이름 칸은 두지 않는다
- submissions 표의 owner 칸에는 로그인한 사람의 구글 메일(st.user 의 메일)을 소문자로 적는다
- 일반 사용자 갤러리에는 owner 가 내 메일인 결과물만 보여 주고, 카드에는 메일 대신 구글 계정 이름을 보여 준다. 관리자(st.secrets 의 ADMIN_EMAILS 에 메일이 있는 사람)는 전체를 본다
- 이미 쌓인 줄은 지우거나 고치지 않는다
- 여러 사람이 동시에 올리는 기능은 PRD.md 비목표이므로 만들지 않는다
- 로그인은 Streamlit 의 st.login 으로 구글 계정만 쓴다. 키 값은 .streamlit/secrets.toml 에만 두고 코드에 적지 않는다
