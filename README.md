# my-service

강사님과 주고받은 메일을 한눈에 보는 화면을 만드는 중입니다.

교육과정을 기획하면서 모듈마다 다른 강사님께 확정 안내를 보내고, 강의안 마감을 리마인드하고,
회신을 기다리는 일이 반복됩니다. 그 상황을 화면 한 장으로 모아 두는 것이 목표입니다.
지금은 왼쪽에서 강사님을 고르면 그분과 주고받은 메일이 오른쪽에 말풍선으로 보이고,
버튼 하나로 답장 초안까지 뜨는 단계까지 만들었습니다.
초안은 Gemini가 그 강사님과 주고받은 메일을 모두 읽고 마지막 메일에 답하는 내용으로 씁니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 한 장 + 메일 이력 예시 자료 |
| `api/draft.js` | 답장 초안을 써 오는 자리. Vercel 서버에서 돌며 Gemini를 부릅니다 |
| `spec.md` | 이 화면의 기획서 (목표 · 입력 · 단계 · 출력) |
| `02_instructors.csv` | 화면에 들어가는 강사 12분의 예시 자료 |
| `.env.example` | 어떤 열쇠가 필요한지 적어 둔 빈 견본 |
| `.gitignore` | 올리지 않을 임시 파일 목록 |

## 보는 방법

Vercel에 올린 주소로 열면 됩니다. `index.html`을 브라우저로 바로 열어도 화면은 다 보이지만,
`답장 초안 만들기`만은 서버가 있어야 해서 "서버에 닿지 못했습니다"라고 뜹니다.

## 열쇠 넣기

초안을 쓰려면 Gemini 열쇠가 필요합니다. 열쇠는 서버에만 두고, 화면에는 절대 넣지 않습니다.

- **Vercel(올린 주소에서 쓸 때)** — 프로젝트 Settings → Environment Variables에
  이름 `GEMINI_API_KEY`, 값은 받은 열쇠를 넣고 다시 배포합니다.
- **내 컴퓨터(연습할 때)** — `.env.example`을 복사해 `.env`로 이름을 바꾸고
  `GEMINI_API_KEY=` 뒤에 열쇠를 붙입니다. `.env`는 깃허브에 올라가지 않습니다.

> 화면에 있는 이름과 메일 주소는 모두 예시 자료입니다.
