# 실습 게시판

## 무엇을 하는 서비스인가

실습 번호만 넣으면 실습마다 결과물 게시판이 한 번에 생깁니다.

- 실습 번호를 넣으면 실습마다 결과물 게시판이 한 번에 생긴다
- 게시판에 이름 · 사진 · 한 줄 설명을 올린다
- 올라온 결과물을 갤러리처럼 모아 본다

노션 갤러리 페이지를 실습마다 복사하지 않고, 결과물을 한곳에서 모아 봅니다.

## 누구를 위한 것인가

실습이 스무 개쯤 되는 과정을 혼자 진행하는 온라인 강사를 위한 서비스입니다.

- 언제 쓰나 : 실습 슬라이드를 넘길 때마다, 그리고 수업이 끝나고 결과물을 확인할 때
- 왜 쓰나 : 실습마다 결과물 받을 페이지를 따로 만들고, 누가 안 올렸는지 이름을 하나씩 대조해야 해서

## 어떻게 쓰나

1. 첫 화면에서 **[시작하기]** 를 누릅니다.
2. 화면 1 「실습 결과물 게시판 만들기」 에서 **실습 번호 (예: 3)** 칸에 1부터 20까지의 숫자를 넣고 **[만들기]** 를 누릅니다.
   - 비워 두면 "실습 번호를 넣어 주세요. 예: 3", 범위 밖의 숫자면 "1부터 20까지 넣어 주세요" 가 보입니다.
3. 화면 2 「만들어진 결과물 게시판」 에서 넣은 번호만큼 생긴 카드 가운데 **[실습 N]** 을 누릅니다.
4. 화면 3 「실습 N」 결과물 게시판 왼쪽에서 **이름** · **사진 (파일 선택)** · **한 줄 설명** 을 넣고 **[올리기]** 를 누릅니다.
   - 사진 1장은 꼭 있어야 하고, 이름과 한 줄 설명은 비워 두어도 됩니다. 사진 없이 누르면 "사진을 1장 올려 주세요" 가 보입니다.
5. 화면 3의 **[결과물 모아 보기]** 탭에서 올라온 결과물을 갤러리처럼 모아 봅니다.
6. 화면 3의 **[내려받기]** 탭에서 **[결과물 내려받기]** 를 누르면, 지금 갤러리에 보이는 결과물이 CSV 파일 하나로 내려받아집니다.
7. 돌아갈 때는 이 단추를 누릅니다.
   - **[← 게시판 목록으로]** : 화면 3 → 화면 2
   - **[← 처음으로]** : 화면 2 → 화면 1
   - 왼쪽 사이드바의 **[← 첫 화면으로]** : 첫 화면으로
8. 어느 화면에서나 오른쪽 아래 **[상담 챗봇]** 을 누르면 대화창이 열립니다. **말투** 를 고르고 **물어볼 말** 을 넣은 뒤 **[보내기]** 를 누르면 이 서비스에 대해 물어볼 수 있습니다. **지난 대화** 를 누르면 예전에 나눈 말이 펼쳐집니다.
