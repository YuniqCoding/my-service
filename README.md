# my-service

강사님과 주고받은 메일을 한눈에 보는 화면을 만드는 중입니다.

교육과정을 기획하면서 모듈마다 다른 강사님께 확정 안내를 보내고, 강의안 마감을 리마인드하고,
회신을 기다리는 일이 반복됩니다. 그 상황을 화면 한 장으로 모아 두는 것이 목표입니다.
지금은 강사님별 카드로 **담당모듈 · 일정 · 장소 · 상태**를 보여주는 단계까지 만들었습니다.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 강사님 한 분을 카드 하나로 보여주는 화면 (브라우저로 바로 열면 됩니다) |
| `02_instructors.csv` | 카드에 들어가는 강사 12분의 예시 자료 |
| `.gitignore` | 올리지 않을 임시 파일 목록 |

## 보는 방법

`index.html`을 브라우저로 열면 됩니다. 따로 설치할 것은 없습니다.

> 화면에 있는 이름과 메일 주소는 모두 예시 자료입니다.
