# 넣으면 나온다

한 줄 : 실습 번호 3을 넣으면 → 빈 결과물 게시판 세 개가 카드 모양으로 한 줄에 나란히 나온다

- 입력 : 쓰는 사람(강사)이 실습 번호를 넣는다 (예: 3)
- 처리 : 넣은 번호만큼 실습마다 결과물 게시판을 한 번에 만든다
- 출력 : 「실습 1」「실습 2」「실습 3」 제목이 붙은 빈 결과물 게시판 세 개가 카드 모양으로 한 줄에 나란히 보인다
- 모양 : 만들어주는 도구 - 핵심 기능이 "번호를 넣으면 게시판이 새로 생긴다"여서, 넣은 것으로 무언가를 만들어 내는 쪽에 가장 가깝다
- 잘못 넣었을 때 : 비워 두고 [만들기]를 누르면, 입력 칸 바로 아래에 "실습 번호를 넣어 주세요. 예: 3"을 눈에 띄게 보여 주고 게시판은 하나도 만들지 않는다
